- **Corrected Record & Audit Analysis**:
  1. **Measured Outcome & Deprecation Rationale**: Python 3.12 exhibits a `7 / 32 ≈ 21.9%` segfault rate under pytest + coverage + Qt widget tests in CI, whereas Python 3.14 is clean (`0 / 30` baseline with `timid = true`). The root cause of the 3.12 segfault remains **unexplained** — Python 3.12 is deprecated to avoid the crash, not because the underlying C/Qt bug on 3.12 was identified or resolved.
  2. **Clarification of commit `a913e04`**: Commit `a913e04` attributed native crashes to coverage's C tracer under Python 3.14. While Python 3.14 with `timid = true` measured 0/30 segfaults, local testing with `timid = false` (C tracer active) reproduced a native segfault under Python 3.14 in `tests/test_app.py`. Thus, `timid = true` IS load-bearing on Python 3.14 to prevent coverage C-tracer frame corruption.
  3. **Timid Setting Resolution**: The round 07 `timid-false` result (`0/10`) was unverified. In round 09 (B22), conftest instrumentation proved `[PYTEST-COV] ACTIVE COVERAGE TIMID = False` reached pytest during run `30686206502` (0/20 in CI). However, the local reproduction of a native segfault when `timid` was removed confirmed that `timid = true` remains load-bearing on Python 3.14.
  4. **Residual Risk**: `0/30` baseline bounds Python 3.14's crash rate under `timid = true` but does not prove zero. A crash rate below ~1-in-30 would not be detected by this sample size. If the defect is a latent Qt-teardown problem that 3.12 merely made more frequent, it could resurface on Python 3.14 under specific thread/event loop timing.
  5. **Second Flake**: `tests/test_app.py::test_app_initialization` intermittently fails with `AppTest script run timed out after 3(s)`. This is unrelated to the native Qt segfault, is in the Streamlit path (slated for removal in Phase 14), and is not fixed here.
  6. **Directional Narrowing**: On Python 3.12, `no-cov` (0/10) and `deselect` widget tests (0/10) are directional results consistent with the crash requiring coverage *and* the Qt widget tests together.
